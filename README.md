# 🎯 AI Object Detection & Tracking

A real-time computer vision application that detects and tracks objects using YOLO and OpenCV.

## 🚀 Features

- Real-time object detection
- Multi-object tracking
- Unique tracking IDs
- Bounding boxes and class labels
- Object counting
- Adjustable confidence threshold
- Webcam detection
- Image detection
- Video detection
- Streamlit web interface

## 🧠 How It Works

The application uses the YOLO object detection model to identify objects in images, videos, and webcam streams.

YOLO tracking maintains object identities across video frames, allowing each detected object to receive a unique tracking ID.

## 🛠️ Technologies

- Python
- YOLO
- Ultralytics
- OpenCV
- PyTorch
- Streamlit
- Computer Vision
