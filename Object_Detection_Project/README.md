# Object Detection Project

## About
This project uses YOLO and OpenCV to detect objects in real time through a laptop webcam.

## Technologies Used
- Python
- YOLO
- Ultralytics
- OpenCV
- PyTorch

## Features
- Real-time object detection
- Webcam support
- Object labels and confidence scores
- Detection boxes around objects
