# 🌐 AI Translation Studio

AI Translation Studio is a multilingual translation web application built with Python and Streamlit.

It allows users to translate text between multiple languages, download translated results, generate speech audio, and maintain recent translation history.

## 🚀 Features

- 🌍 Multilingual text translation
- 🔄 Source and target language selection
- 🌐 REST API-based machine translation
- 🔊 Text-to-Speech audio generation
- 📥 Download translated text
- 🕘 Translation history
- 📊 Word and character count
- ⚠️ Error handling
- 💻 Interactive Streamlit web interface
- 🌏 Support for 20+ languages

## 🛠️ Technologies Used

- Python
- Streamlit
- Requests
- MyMemory Translation API
- gTTS
- REST API
- Natural Language Processing (NLP)
